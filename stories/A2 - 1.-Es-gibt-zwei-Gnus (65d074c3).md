# 1. Es gibt zwei Gnus.

1. Es gibt zwei Gnus.
2. Sie stehen in der Savanne.
3. Sie schauen auf den Stein.
4. Ein Gnu sagt: "Das ist ein Löwe."
5. Ein anderer sagt: "Nein. Das ist kein Löwe. Das ist eine Antilope."
6. Sie streiten sich. Jemand sagt, dass es ein Löwe ist. Der andere denkt, dass es eine Gazelle ist.
7. Das ist das Gnu, das denkt, dass es ein Löwe ist.
8. Er nimmt einen Stein. Dieses Gnu wirft den Stein auf einen großen Felsen.
9. Der große Stein bewegte sich nicht.
10. Jetzt geht das Gnu näher.
11. Er geht noch näher... und näher... und näher...
12. Er fällt in ein Loch.
13. In dem Loch gibt es Wasser. Das ist ein Teich.
14. Er nimmt einen Stock. Er wirft den Stock auf den Stein.
15. Der zweite Gnu sagt: "Es gibt ein Loch."
16. Die Löwin geht.
17. Die Löwin kommt.
18. Die Löwin schaut auf das Gnu.
19. Die Löwin sagt: "Mmm... Fleisch!"
20. Das Gnu erschrickt sich.
21. Das Gnu stürzt sich in das Loch.
22. Das Gnu sagt: "Es gibt einen Löwen!"
23. Der andere Gnu sagt: "Es gibt ein Loch und einen Stein!"
24. Eine zweite Löwin kommt.
25. Die beiden Löwinnen schauen auf das Gnu.
26. Die zweite Löwin sagt: "Es gibt zwei Fleischstücke."
27. Die Löwinnen schauen nach vorne.
28. Die Löwinnen erschrecken sich.
29. Die Löwinnen rennen weg.
