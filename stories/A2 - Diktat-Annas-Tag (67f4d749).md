# Diktat: "Annas Tag"

Diktat: "Annas Tag"
Anna ist Studentin. Heute hat sie einen vollen Tag. Sie muss früh aufstehen, weil sie pünktlich an der Uni sein will. Im Bus kann sie endlich Musik hören. In der Uni soll sie einen langen Text lesen, aber sie möchte eigentlich lieber Kaffee trinken.
Nach dem Unterricht darf sie mit ihren Freunden ins Café gehen. Das macht ihr Spaß! Aber sie muss um 18 Uhr nach Hause fahren, denn abends will sie eigentlich fernsehen. Leider kann sie das nicht – sie muss noch für eine Prüfung lernen. Anna seufzt: Morgen möchte sie mehr Zeit für sich haben.
